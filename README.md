# Interactive Dashboard

This project is a simple interactive dashboard built with Python and Streamlit.

## Features

- Interactive filters for regions and sales threshold
- Summary metrics for total sales and profit
- Visual charts for sales and profit
- Data table view for the filtered results

## Requirements

Make sure you have Python installed, then install the dependencies:

```bash
pip install streamlit pandas
```

## How to run

Run the app from the project folder:

```bash
streamlit run main.py
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:8501
```

## Project files

- main.py - the Streamlit application
- README.md - project documentation
